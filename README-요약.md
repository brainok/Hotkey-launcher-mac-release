# README-요약

Hotkey Launcher는 macOS 메뉴 막대에서 실행되는 단축키 런처로, 자주 쓰는 앱과 폴더를 전역 단축키로 빠르게 열고 짧은 텍스트 트리거를 긴 문구로 자동 치환할 수 있습니다. 오프라인 Activation Code와 30일 Trial을 지원하며, 설치 후 손쉬운 사용 및 입력 모니터링 권한을 허용하면 macOS 어디서든 반복 작업을 더 빠르게 처리할 수 있습니다.

Hotkey Launcher is a macOS menu bar hotkey launcher that opens frequently used apps and folders with global shortcuts and expands short text triggers into longer saved phrases. It supports offline Activation Codes and a 30-day trial, and after granting Accessibility and Input Monitoring permissions, it helps speed up repeated work across macOS.
