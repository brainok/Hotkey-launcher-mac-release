# Hotkey Launcher

Hotkey Launcher는 macOS 메뉴 막대에서 실행되는 Swift 네이티브 단축키 런처입니다. 앱과 폴더를 전역 단축키로 실행하고, 짧은 텍스트 트리거를 긴 문구로 자동 치환하며, 오프라인 Activation Code로 라이선스를 관리합니다.

## 다운로드

최신 DMG:

https://github.com/brainok/Hotkey-launcher-mac-release/releases/latest/download/Hotkey-Launcher.dmg

## 설치

1. `Hotkey-Launcher.dmg`를 엽니다.
2. `Hotkey Launcher.app`을 `Applications` 폴더로 드래그합니다.
3. `/Applications/Hotkey Launcher.app`을 실행합니다.
4. 전역 단축키와 텍스트 치환을 사용하려면 macOS `시스템 설정` -> `개인정보 보호 및 보안`에서 `손쉬운 사용`과 `입력 모니터링` 권한을 허용합니다.

## 주요 기능

- 앱 등록 후 전역 단축키로 어디서든 실행
- 폴더 등록 후 Finder에서 즉시 열기
- 실행 중인 앱을 앞으로 가져오거나 이미 앞에 있으면 숨기기
- 짧은 텍스트 트리거를 저장된 문구로 자동 치환
- 메뉴 막대에서 Settings, Activation, Reload, Dark mode, 로그인 실행, About, Quit 관리
- 30일 Trial과 오프라인 Activation Code 지원
