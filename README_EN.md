# Hotkey Launcher

Hotkey Launcher is a native Swift macOS menu bar app for launching apps and folders with global hotkeys, expanding short text triggers into longer phrases, and managing offline activation codes.

## Download

Latest DMG:

https://github.com/brainok/Hotkey-launcher-mac-release/releases/latest/download/Hotkey-Launcher.dmg

## Install

1. Open `Hotkey-Launcher.dmg`.
2. Drag `Hotkey Launcher.app` into `Applications`.
3. Launch `/Applications/Hotkey Launcher.app`.
4. To use global hotkeys and text expansion, allow `Hotkey Launcher` in macOS System Settings -> Privacy & Security -> Accessibility and Input Monitoring.

## Key Features

- Register apps and launch them from anywhere with global hotkeys
- Register folders and open them directly in Finder
- Bring a running app forward, or hide it when it is already frontmost
- Expand short text triggers into saved replacement phrases
- Manage Settings, Activation, Reload, Dark mode, launch at login, About, and Quit from the menu bar
- Supports a 30-day trial and offline Activation Codes
